# Datasets

Every dataset the system reads, with its real header and a real row. Figures
here were read out of the seeded database on 2026-08-19, not estimated.

## Honesty statement, up front

**The product catalog is generated, not scraped.** Every row carries
`is_simulated: true`, every price is invented, and `MARKET_A/B/C` are fictional
marketplaces — they are not Amazon, Flipkart or Myntra under other names. The
UI labels this on every card (`SimulatedBadge`) and the API returns the flag.

Nothing in this repo claims a real-time price. See
[README](../README.md) for why the real marketplaces are not integrated
(Amazon's Creators API needs a qualifying sales history, Flipkart's affiliate
programme is closed to new signups, Myntra publishes no product API).

## 1. Product catalog — `data/products/catalog.json`

The primary dataset. Generated by [`scripts/generate_catalog.py`](../scripts/generate_catalog.py),
loaded by [`backend/scripts/seed.py`](../backend/scripts/seed.py) into the
`products` table.

**3,075 products · 3.6 MB · 15 categories · 69 subcategories · 27 brands**

**Known gap:** there are no phones, no large appliances and no vehicles. A
search for "mobile" is answered with "I do not have any mobile in this
catalog", not with a substitute.

**Known quirk worth knowing before a demo:** `machine_washable` appears in
descriptions, so a TF-IDF search for *"washing machine"* weakly matches a
fleece jacket. The token overlap is real, so the honest fix is a curated
synonym list rather than a similarity threshold tuned on one example.

## 4. Goal knowledge base — `backend/app/kb/goals/*.yaml`

Hand-authored, not learned. Five goals: `trek`, `winter_trek`, `camping`,
`apartment_setup`, `laptop_purchase`. This is what turns a goal into a
requirement list in Mode B.

```yaml
key: winter_trek
extends: trek                 # merges parent items field-by-field
display_name: Winter Trekking
domain: outdoor
aliases: [winter trek, snow trek, cold weather trek, himalayan trek, manali trek]

context_defaults:
  region_type: mountain
  season: winter
  temp_min_c: -5

items:
  - key: trekking_socks
    item_name: Thermal Woolen Socks
    required_features: [thermal]
    preferred_features: [moisture_wicking, quick_dry, anti_bacterial]
    reason: "Wool retains warmth even when damp; cotton socks in the cold are how you get frostnip."
    est_price_range: [350, 1400]
```

`required_features` and `est_price_range` are the fields that link the KB to
the catalog — and, as [EVALUATION.md](EVALUATION.md) records, they are also the
fields the relevance labels are built from, which is why the headline ranking
numbers are an upper bound.
